# Hecate ecosystem (GitHub)

| Repository | Role |
|---|---|
| [hecate](https://github.com/codebfu/hecate) | Server API, UI, MCP, protocol crate |
| [hecate-propylaea](https://github.com/codebfu/hecate-propylaea) | Internet-facing agent proxy |
| [hecate-lampad-helper-base](https://github.com/codebfu/hecate-lampad-helper-base) | Shared helper IPC wire protocol |
| [hecate-lampad-core](https://github.com/codebfu/hecate-lampad-core) | Agent-side shared logic |
| [hecate-lampad](https://github.com/codebfu/hecate-lampad) | Multi-OS lampad agent |
| [hecate-lampad-desktop](https://github.com/codebfu/hecate-lampad-desktop) | Desktop GUI helper |
| [hecate-lampad-proxmox](https://github.com/codebfu/hecate-lampad-proxmox) | Proxmox VM console helper |
| [hecate-repo](https://github.com/codebfu/hecate-repo) | Signed feature repository CLI |

## Private umbrella mapping

This public split is exported from a private monorepo layout. Components under `ansible/`, GitLab CI, and `.cursor/` are intentionally excluded from GitHub.
